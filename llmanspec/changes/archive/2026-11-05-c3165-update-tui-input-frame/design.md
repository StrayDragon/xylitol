# Design — 修复输入框边框、光标与标记落点

## 输入框形态

```
╭────────────╮
│ line 1     │
│ line 2     │
❯ line 3     │
╰──── [▤ 摘要] ◨
```

- 内容行保留编辑器原始 ANSI；只把首尾 padding 空格替换为 `│`。
- 末行左 padding 替换为用户 glyph；右 padding 替换为 `│`。
- 下边框右端用 `◨` 替代 `╯`；窄档 `<80` 仍用 `╯` 并隐藏 `◨`。

## 命中

- `try_click_painted_chip` 先找 `◨` 在行内的可见列，命中 `[marker_col-1, marker_col+1)`。
- 侧栏开启后行尾追加侧栏内容，不再用整行宽度推断 marker。

## 省略号

- 边框内部截断使用空省略号；纯虚线截断不得显示 `…`。
