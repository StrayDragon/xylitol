# 产品位：统一 CS 双端形态与能力归属

> **状态：purpose-draft** —— 只钉产品行为与能力归属，**不含技术实现、不列可选方案**；细节（协议变体、命令表、实现切片）由后续 change 经 `depends_on` 分阶段填充。
> 依据：`c2280-add-tui-attach-driver-ssot`（research `02-split` 能力归属观察 / `00` 术语）；形态方向经用户定调：**统一 CS**——TUI 恒为客户端，"进程内默认"只是 host 的嵌入形态。

## Why

当前产品把全部逻辑跑在终端进程内，且存在"进程内 vs 远程"两套语义混用的风险。目标是把产品收敛为**一个稳定的客户端-服务端形态**：TUI 永远是薄客户端（呈现 + 采集输入），host 承载全部操作器能力，二者经唯一稳定的命令/事件契约通信。默认单命令运行与显式 attach 走同一条契约、同一套能力归属；先钉死**能力归属与启动/连接方式**，为协议、多会话、符合性闸等后续实现 change 提供共同地基。

## What Changes

产品位定义：

### 双端形态

- TUI 是**薄客户端**：只把界面和输入呈现给用户，把用户意图编码为命令发出、把事件渲染为界面；不运行 ReAct/工具/MCP/工作区。
- host 是**操作器**：承载模型、会话、资源装配与工作区执行的全部能力。

### 能力归属（哪些归 client、哪些归 host）

**client（面 / 面前端）：**

- 呈现与交互：键盘、绘制、终端协议、输入框编辑与 `$EDITOR`。
- 本机硬件的面能力：剪贴板读 / 写 / 图片粘贴（含 OSC 52）。
- 本地文件操作：会话**导出写盘**、**导入读取**（"人在本机坐的这台机器"是自己的主位）。
- 把用户意图编码为命令发出；把 host 推送的事件渲染为界面。

**host（操作器）：**

- 模型与推理：模型选择与切换、thinking 级别、运行 / 中止回合。
- 会话生命周期：新建 / 切换 / 命名 / 删除、消息读取、统计、压缩、fork。
- 资源装配：配置、prompt、模型注册表、MCP、工具集、reload。
- 工作区执行：全部工具、MCP、**工作区 bash（含 `!` / `!!`）**。
- 信任持久化：`/trust` 写入 host 侧项目信任文件。

**归属判定原则：** 凡能力依赖工作区 / 仓库 / 模型 / MCP → host；凡能力依赖本机终端 / 本机硬件 / 用户坐的这台机器 → client。`!ls` 列的是 host 的工作区，不是客户端机器的 cwd。会话数据归 host；"导出到本机路径写盘"归 client（host 给内容、client 写盘）。

### 启动与连接方式（launch & connect modes）

- **host 唯一性**：host 是**每台机器唯一**（或每个系统运行时唯一——例如 Docker 里一个容器一个 host）；跨进程交互经网络传输处理。
- **候选形态（开销已实测，进入产品判定）**：
  - **A. 统一 CS**：TUI 恒连 host，同机也走协议 / 网络。实测载体开销可忽略（`research/overhead-eval.md`：p99 ≤ 0.5 µs、容量 ≥ 320k fps，均超 500 tok/s 门槛 3 个数量级）→ **默认取 A**，代码路径唯一、SSOT 最稳。
  - **B. 单进程自持**：TUI 与 host 同进程、进程内直连（今天的形态），契约同源、载体为进程内直调。保留与否**不再由性能决定**，只看「单窗多一个 host 进程」的进程税与启动体感（产品体验判定）。
  - **契约不变**：无论 A / B，TUI 与 host 走的是同一套命令 / 事件契约（协议闭集唯一）。
- 显式 `--attach` = 连接一个已运行的 host（同机或同系统运行时的 host）。
- 生命周期：关一扇 TUI 不终止 host；host 停止则所有连接的 TUI 断开。

### 多窗与会话写入规则

- host 知道每个 session 当前被多少 TUI client 连接。
- 一条 session **同一时刻只有一个写者**（当前持有写入的 client）。
- 把另一个 TUI attach 到一个**已被其它 client 写入的 session** → 得到**只读静态恢复**视图：不是 tmux 式共屏写，只是恢复查看当前正在被写入的 session。
- 在该只读 session 上发起对话（写）→ 报错提示「有其他 TUI 已连接，当前仅只读」。

- 不考虑 Web / 其它客户端面（只保证契约与形态不堵未来客户端）。
