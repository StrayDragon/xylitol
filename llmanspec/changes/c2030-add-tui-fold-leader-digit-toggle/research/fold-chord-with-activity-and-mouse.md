# Research: 折叠和弦 × 聚合折叠 × 鼠标路径（联合决策）

> c2030 拍板输入。结合 `c1760` / `c2020✓` / `c2040` / `c2050` 与终端调研。

## 1. 产品时间线里的「谁解决定点」

```text
今日          只有全局 Alt+E / Ctrl+T / Ctrl+O（粗）
     │
c2030         键盘定点：leader + digit（无鼠标可用）
     │
c1760         段级 L2/L3 + Alt+Shift+E 栈（聚合折叠）
     │
c2040         鼠标点三角 → 同套 fold.toggle（有鼠标主路径）
     │
c2050         段+块统一目标：点摘要 / leader 可混编
```

**用户定性（2026-08-11）**：c2030 = **无 mouse 时的替代方案**；mouse 完整点击三角后，键盘定点压力 **大幅缓解**。

推论：

| 投资 | 高 ROI | 低 ROI（可后置） |
|---|---|---|
| 共用 `fold.toggle` + per-block 覆盖表 | ✓（c2040 硬依赖） | |
| `Alt+E`→leader（无鼠标能定点） | ✓ | |
| 全局 tools 仍可达（勿静默删） | ✓ | |
| 每个轴都严格「原键 leader + Shift 全局」对称 | | 鼠标落地后收益薄 |
| Thinking / Ctrl+O 也 leader 化 | | 首波不值得 |
| 抢 `Alt+Shift+E` 给 L1 全局 | | 与 c1760 段栈长期打架 |

## 2. 三层折叠心智（应对齐旁注，而不是抢同一键）

| 层 | 语义 | 键盘（意向） | 鼠标（后） |
|---|---|---|---|
| **L1 块** | 单个 tool/diff/ask 显隐 | leader+digit / 全局另键 | 点块头三角（c2040） |
| **L1 视口** | 已展开块的高度 | `Ctrl+O` 保持全局 | 一般不需要点 |
| **L2/L3 段** | 活动摘要 / Worked for | `Alt+Shift+E` 升、`Ctrl+Alt+Shift+E` 降（c1760） | 点摘要三角（c2050） |

c1760 深挖 A：**段在 L2/L3 时，L1 全局/覆盖不穿透该段外观**——和弦必须分层，旁注 L2 行写 `(Alt+Shift+E)` 不写 `(Alt+E)`。

## 3. 对 α/β/γ 的联合重评

| 方案 | 对 c1760 | 对「键盘=临时替代」 | 对 c2040 | 翻车风险 | 联合评分 |
|---|---|---|---|---|---|
| **α** Alt+E=leader；全局 `Alt+Shift+B`；保留 c1760 `Alt+Shift+E` | 友好 | 够用 | 覆盖表就绪 | 低 | **首选** |
| **β** 全局抢 `Alt+Shift+E`；c1760 改绑 | 伤（改已拍） | 稍贴肌肉记忆 | 同左 | 中高（两案文档/旁注） | 不推荐 |
| **γ** Alt+E 仍全局；leader 另键 | 友好 | 弱（无鼠标时多学一键） | 同左 | 最低 | 若强保守可选 |
| **δ** 全家 leader | 乱 | 过度设计 | 同左 | 高 | 否 |

**鼠标缓解后的稳态 UX**：

- 有鼠标：点三角（L1/L2）为主；键盘段栈 `Alt+Shift+E` 仍有用（「剥最近一段」不必瞄准）。
- 无鼠标 / SSH / 关 capture：`Alt+E`+digit 仍是 L1 定点唯一舒服路径 → **α 的 leader 重载仍值得**，不是过渡期废物。

## 4. 修订推荐（联合版 · 方案 α′）

在 α 上按「键盘替代 + 少对称」收一刀：

| 动作 | 默认键 | 备注 |
|---|---|---|
| L1 **leader** | `Alt+E` | 视口≤10 编号；打字/Esc 取消；digit 非 `Alt+digit` |
| L1 **全局** tools | `Alt+Shift+B` | 清空 overrides 或改 default+清表（钉一种） |
| Compaction 全局 | `Alt+Shift+C` 或首波仍跟全局 tools 一次翻 | 倾向拆出，避免 leader 平面混默认 |
| Thinking | `Ctrl+T` **保持全局** | 不做 leader |
| 视口 | `Ctrl+O` **保持** | 不做 leader |
| 段展开/收纳 | **不动** c1760 | `Alt+Shift+E` / `Ctrl+Alt+Shift+E` |
| 鼠标 | c2040/c2050 | 与 leader **同** `fold.toggle` |

**明确不做（本波）**：β 抢键；thinking/Ctrl+O leader；随滚动持续重标；默认 `Alt+digit`。
