# Human checklist — c2040 fold triangle

最短路径（ApplicationOwned 产品 TUI）：

1. 开会话，跑出至少一个 tool 块（或 Ask）。
2. **点三角列** → 该块收起/展开；其它块不变。
3. **点头行正文/旁注** → 不 toggle；可选拖选复制仍可用。
4. **Alt+E** → 全局 tools 翻转，先前单块覆盖消失。
5. 若有 Thinking：点其一三角只动该块；**Ctrl+T** 清 thinking 覆盖并全局翻转。
6. Ascii：`XYLITOL_TUI_GLYPH_SET=ascii` 见 `>`/`v`。

终端（建议）：Ghostty / tmux；SSH 可选。
