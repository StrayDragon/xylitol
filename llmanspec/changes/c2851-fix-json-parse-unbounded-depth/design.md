# Design — 深度上限取值与实现形态

## 决策表

| # | 决策 | 取舍 |
|---|---|---|
| D1 | 上限 **2048** | 合法深树实机观测 188 层；余量 10 倍。再深已无产品语义（树深 ≈ 会话分支深度）。默认 128 是误伤源，无界是栈风险源——2048 居中且远低于栈极限（数 KB/帧递归栈 × 2048 ≈ 数 MB 内）。 |
| D2 | 前置字符扫描深度计数（std，单趟） | serde_json 无内建深度上限；自写 Visitor 重于收益。字符串字面量内的 `[`/`{` 需跳过（带转义感知的最小词法扫描，仍 std-only）。 |
| D3 | 超限走既有降级（服务端 None→400 非法信封；客户端 RawOk→Null） | 与 r1907「不拼半份形状」一致，不发明新错误面。 |
| D4 | 两处入口共用同一常量与探测函数（codec.rs 导出，客户端复用） | 单一事实源，防止两入口上限漂移。 |

## 失败模式

- 误伤：合法 >2048 层载荷被拒——按 c2846 判据无此产品场景；如出现，调常量即可（单点）。
