## 2. 一句话目标

把产品 TUI 的 5 个痛点——长输入占满 scrollback、thinking 流式展开后突然折叠、高 token 速率下 CPU 打满、工具参数没有折叠层、详情 overlay 与编辑区 chrome 难看——拆成 8 个原子 change，按依赖顺序从 `designed` 推进到 `full + verify + finalize`。

默认体验：

- 折叠默认 **summary**：已结束轮折成信封，流式 thinking 只占一行。
- **阶段名**：首轮用户消息 + 首个结果后独立请求模型生成；默认只一次；改名钉住；refresh 才覆盖。
- 编辑区 chrome：**rounded + 右对齐阶段名 + 输入行 `◨` + 下边框 `[▤ 摘要]` + 固定 `⬢` 颜色脉冲**（B+E+D）。

### 3.2 为什么拆 8 个

- 每个 change 独立可校验、可归档；不把「阶段名 / 折叠 / chrome / 性能 / 引擎」塞进一个大 change。
- 依赖边明确：c3115 依赖 c3110；c3125 依赖 c3120；c3130 依赖 c3115 + c3120。
- 性能与引擎接入独立，可在不同 worktree 并行；同 crate 不得共用 `CARGO_TARGET_DIR`。

## 7. Apply 协议

### 7.1 每个 change 的顺序

```text
读 proposal + design
→ llman-sdd validate <id> --strict
→ llman-sdd change start <id>（或 attach）
→ 从 design 的「实施任务」生成 tasks.md
→ 编辑 live specs + commit
→ apply（代码 + 测试）
→ llman-sdd verify
→ llman-sdd change finalize <id>
→ 更新本文件进度
```

### 7.2 命令

| 目的 | 命令 |
|---|---|
| 结构校验 | `llman-sdd validate <id> --strict` |
| 绑定分支 | `llman-sdd change start <id>` / `attach <id>` |
| 全量结构 | `llman-sdd validate --all` |
| 日常 | `just fmt` / `just lint` / `just test` / `just test-tui` |
| 全量门禁 | `just qa quiet`（CI 同命令） |
| 真终端 | `just test-tui-e2e-pty` / `just qa-e2e` |

### 7.3 纪律

- 一次只做一个 change；不要并行改同一 crate 的同一区域。
- 同 crate 的并行 worktree 不得共用 `CARGO_TARGET_DIR`。
- `tasks.md` 必须从 design 的「实施任务」生成，不得跳过。
- specs 必须在 apply 前落地并 commit；不得只改代码不改 spec。
- 每个 change 完成后跑 `just fmt` / `just lint` / `just test-tui`；全量 `just qa quiet`。
- 失败先读错误；不要盲重试；遇到用户拥有的产品语义选择才停，给编号选项。

## 10. 风险 / 待确认

- **重置 chip 落点**：设计取「下边框、折叠 chip 左侧；仅在有覆盖时出现」。用户草图未包含重置 chip；若要换位置，apply 前确认。
- **`◨` 宽度**：tmux 3.8 实测 1 列；部分终端可能 ambiguous 宽 2 列；若错位回退 `▐` / `▥` / ASCII `|`。
- **`◨` 占内容行 2 列**：会减少输入宽度；窄档隐藏；snapshot 验证长输入换行不重叠。
- **折叠 chip 下边框**：`paint_editor_chips` 目前只处理第一行；需要同时处理下边框；避免与 footer 命中冲突。
- **spinner 颜色脉冲**：若 `Loader` 对 frames 做颜色包装，需预着色 frames 或 per-frame color；不得让 ANSI 影响宽度。
- **阶段名延迟**：生成是异步的，标题可能晚数秒；失败回退；不阻塞主回复。
- **CPU 目标**：release 1000 delta/s <20% 是 macOS 本机目标；Windows / 其他终端未验证；真实 provider 速率不同。
- **c3145 fd**：fd 不存在时回落 read_dir；收益取决于环境；不做缓存 / 异步。
- **c3130 详情下线**：会话 id 入口改由会话树 `app.session.toggleId`；需在文档/帮助提示。
- **eval**：`c3006-add-minimal-eval-harness` 保持 FROZEN；不启动、不改 tasks。
