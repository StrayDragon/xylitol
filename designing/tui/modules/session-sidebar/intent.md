# session-sidebar

常驻右列第二列（会话侧栏）。不是槽，不是待办栏；与覆盖弹出框显隐互不影响。

- `Alt+u` 二态切换；开启时正文按「全宽 − 侧栏宽」重排换行，关闭恢复全宽。
- 仅标准档（≥80 列）及以上渲染；极窄 / 窄档 `Alt+u` 降级打开覆盖弹出框
  （不占列，Esc 收起），不得在窄档渲染侧栏。
- 右缘整高：muted `│` 分隔 + 信息列；现为施工中占位两行
  （「实验特性 · 施工中」「正式业务后启用」）。
- 滚动条贴内容右缘（侧栏左缘）；侧栏带内滚轮不滚正文、选区不得进入。
- 通知栈与覆盖弹出框按内容宽收口，不得压住侧栏。
- 禁止冒充待办栏或槽；禁宽度动画、阴影卡片。
