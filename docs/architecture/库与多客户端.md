# 库与多客户端

> 用户/产品视角：同一内核如何被多种 client 与嵌入方共用。不写 API 签名与模块路径。

## 用户怎么碰到

- **TUI**：终端交互端（**CLI 默认入口**）。产品路径是四象限客户端，默认 attach 本机 Host；未在听失败。
- **Print**：本地一次性对话，开箱主路径之一；同进程，不占端口。
- **Host**：操作器（模型 / 会话 / MCP / 工作区 / trust）。显式 `xylitol serve` 才占用绑定。
- **嵌入库**：外部程序把 xylitol 当库，自建界面；同进程。

用户改向（插话 / 续跑 / 中止）只经统一的“驱动”入口，不直达对话循环内部。

## 一条主线（产品）

```text
装配 → 驱动（进程内或远程）→ 对话循环 → 统一事件流 → 该端渲染
```

**心智（命名不改代码）**：`XyDriver` 是 Print / TUI / Host / 嵌入共用的**统一交互内核**——整机遥控器：跑一轮、改向、会话与模型命令都经此入口，不直达对话循环内部。实现类型名继续叫 Driver；产品端角色不必强行 `Xy*App` 品牌化。

```mermaid
flowchart LR
  Clients["Print / TUI / Host / 嵌入"] --> XyDriver["统一驱动 / 交互内核"]
  XyDriver --> Loop["对话循环"]
  Loop --> Events["统一事件流"]
  Events --> Render["各端各自渲染"]
```

## Client 矩阵

| Client | 角色 | 今日状态 |
|---|---|---|
| **TUI** | 终端交互（默认） | attach 本机 Host；未在听失败 |
| **Print** | 本地一次性对话 | 同进程主线 |
| **Host** | 操作器 + 可选监听器 | 产品 TUI 依赖本机在听；print / 嵌入不占端口 |
| **嵌入库** | 外部自建端 | 公开装配缝 + 精选契约 |

## 两层对外契约（产品规则）

| 层 | 给谁 | 写什么 |
|---|---|---|
| **库契约（`Xy*`）** | 替换端口、跨端事件、**共享应用协议（`XyDriver`）**、配置元数据 | 精选稳定符号（见 `src/AGENTS.md` / crate 根 `pub use`） |
| **装配辅助** | 多 client / 嵌入方 | bootstrap、`BuildAgentOptions`、dispatch、（可选）线协议 |

需要新能力时扩 `XyDriver` / 事件 / 端口，不得伸手进内部实现。

**端侧**：键、画、TTY、剪贴板、折叠/展开等框架动作由 TUI 自己做；Host 不管视口。

## 跨端公共体验（已开放端）

凡**已开放**的产品端（今日：Print / TUI / Host），对会话 / 改向 / 能力开关必须**语义同源**；表现可异。未开放端（gpui 桌面等）不得写成现行必须。

| 同源 | 同貌 |
|---|---|
| 驱动命令与事件闭集 | 像素布局、信息密度、控件皮肤 |
| 会话 / 队列 / 中止 / 分支 | — |
| **公共能力**的动作语义与学习模型 | 某一端**独有**能力的交互 |
| 公共能力的快捷键 / 发现路径宜同构（OS 修饰键可映射） | 强制物理键帽字节级相同 |

| 必须 | 不得 |
|---|---|
| 两端描述同一会话时状态可对上 | 静默分叉第二套会话语义 |
| 能力开闭共用事实 | 某一端已关、另一端仍当已开 |
| 新开放端接入时核对着齐全套同源词汇 | 为赶某一端另起一套进度故事 |
| 设计/改 **公共**交互时按“一套学习成本”验收 | 只为某一端发明第二套公共故事；把端专属键位写成公共必须 |
| 改公共交互相关 architecture / 各端 `AGENTS` 前先核对全部已开放端 | 静默开出“只教某一端”的第二套公共故事 |

分界：先问“这是不是两端都会有的能力？”——是 → 语义与理解成本必须一套；否（纯 TTY / 纯 GUI）→ 可分叉，不得污染公共词汇。

## 嵌入方产品规则

1. **优先**公开装配缝 + 精选库契约。
2. **不得**把内部实现类型当稳定 API。
3. 未配置的能力（如 MCP）必须 **zero-cost**。
4. 已知泄漏与非承诺项 → 一行见 `src/embed.rs` 文档注释；不在此展开。

## 理想 vs 现状

| | 状态 |
|---|---|
| Print / Host / 嵌入走统一驱动 | 已交付 |
| TUI 消费同一事件流（会话、steer、slash、bang…） | attach 路径（现行唯一产品端拓扑） |
| CLI 默认进 TUI | 本机 Host 必须在听 |
| 产品 TUI 是薄客户端、操作器在 Host | 默认 attach；print / 嵌入仍可同进程 |
