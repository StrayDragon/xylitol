# 进程内观测

> 用户/产品视角：排障时对照「线路所见」与「产品理解」，并可选择把同一时间线导出到标准 OTLP。
> 现状对齐：2026-09-08。

## 用户怎么碰到

开发者或深度用户想回答：这一轮对上游发了什么、收回了什么？是线路上的内容错了，还是本地映射错了？过程树与工具状态如何？

今日可用：

1. **进程内对照底座**（本地时间线 / `provider-trace.jsonl` + 窄读脚本）
2. **可选 OTLP 出口**（配置显式开启；默认不收集）→ 常直连 Langfuse，也可指向其它 OTLP 后端
3. **同 turn 过程树**（观测闸开启时）：`agent.turn` 根下挂 `agent.iteration` / `llm.request` / `tool.execute`；真·压缩另有 `agent.compaction`；用量结算有 `token.estimate`；abort 终态可标 ERROR

**不**自研 Inspect 检视台作主路径。

## 多总线（正交，禁止合并）

同一业务点若既要刷新界面又要排障，**并列**发射——不要发明一个兼做 UI 的「signal」。

| 总线 | 角色 | 典型去向 |
|---|---|---|
| **`XyEvent` / `XyEventSink`** | 产品生命周期闭集 | TUI / Print 渲染（见 [用户可见事件.md](./用户可见事件.md)） |
| **`XyHookBus` / hooks** | 观察或 block/modify 扩展 | 脚本与库钩子 |
| **fastrace spans** | 过程树 / 时长 / 属性 | 本地 JSONL + 可选 OTLP 消费端 |
| **`log`** | 诊断文案 | 文件日志 |

`XyEvent`（如 `CompactionStart`）**不是** OTel 事件；fastrace span 名（如 `agent.compaction`）**不驱动** TUI。

## fastrace 能做什么 / 不能做什么

| 能力 | 是否本职 | 说明 |
|---|---|---|
| 产品过程树、父子、属性、OTLP 导出 | 是 | 观测主路径 |
| 闸关 ≈ 零开销埋点 | 是 | 与本地 JSONL / OTLP 闸联动 |
| TUI 刷新、通知、面状态 | **否** | 走 `XyEvent` |
| 可取消 / 改写请求 | **否** | 走 hooks |
| 依赖库要原生 OTel `Context` | 有限 | 仅允许桥接 attach，**不**另建第二棵 xylitol 过程树 |

**禁止**业务埋点直接用第二套 OTel/`tracing` SDK 并行发 span（双父上下文、双导出、难对齐 session）。唯一 OTLP 出口在 fastrace Reporter。未来 Metrics / 告警若需要，走独立管道，不用假 span 冒充通知。

## 发射 → 传输 → 消费（心智）

```text
业务点 ──并列──► XyEvent（面） / hooks（扩展） / fastrace（观测）
                              │
                         FanoutReporter
                    ┌─────────┴─────────┐
                    ▼                   ▼
           provider-trace.jsonl    单一 OTLP/HTTP
                                         │
                    ┌────────────────────┼────────────────────┐
                    ▼                    ▼                    ▼
              直连 Langfuse      （理想）Collector      其它 OTLP 后端
              （今日常见）         ├─ lane=llm → Langfuse
                                  └─ lane=infra → Tempo/Grafana
```

- **Emit**：产品 span 名 + 父子树；（理想）`xylitol.obs.lane=llm|infra` 仅挂在 span 上
- **Transport**：单一 OTLP + 可选本地 JSONL；默认远程关闭；坏配置不挡对话
- **Consume**：Langfuse = LLM/agent 数据集与过程树；Tempo/Grafana = 失败体验 / infra（理想经 Collector）

应用内**不做**双 exporter；分流在 Collector（或直连 Langfuse 时应用侧不发射污染 LLM 的 span）。

## 产品 span 目录（导出名）

| 名 | 角色 | 备注 |
|---|---|---|
| `agent.turn` | 一轮用户触发的根 | session id；abort 可 ERROR |
| `agent.iteration` | ReAct 一代 | 挂在 turn 下 |
| `llm.request` | generation | usage / 可选 I/O 档 |
| `tool.execute` | 工具 | 并行须共享 iteration 父 |
| `agent.compaction` | 真·会话压缩 | 过 prepare 后；含 `reason` |
| `token.estimate` | 用量结算 | 一轮 TurnSettled 至多一次 |

另有 `react.error` / `tool.error` 等错误 span；lifecycle **事件**挂在 span 上，不是独立导出名。

## 产品规则（MUST / 禁止）

| MUST | 禁止 |
|---|---|
| 显式调试档才持续记录敏感载荷 | 默认把完整请求体永久明文甩到不可控处 |
| 能对照「线路所见」与「产品理解」 | 只给映射后结果、无法证伪通道错分 |
| 用窄读工具/配方读本地 trace | 把外挂 MITM 写成产品主路径 |
| 远程 OTLP 默认关闭；坏配置降级 | 因观测失败阻断对话主路径 |
| 观测时间线仅 fastrace + `log` | `tracing` / 第二套 OTel span 栈 |
| UI 与观测分总线并列发射 | 用观测属性兼做 TUI/通知总线 |

| 子进程出站观测 | ❌ 候选 |
