# 术语表（黑话 ↔ 标准词）

> 文档召回锚点：agent / 新人按自然语言检索时，凭本表把内部黑话映射到可搜的标准词与英文。
> 用法：新写作黑话首现须附本表标准词或英文对照（根 `AGENTS.md` 工作原则）；编号引用带语义尾，追溯经 `llman-sdd archive freeze --list`。

## A. SDD 流程词

|---|---|---|---|
| 满闸 | 全量门禁 | QA gate | `just qa` 全量质量流水线 |

| 冻结（流程义） | 冷归档 | freeze-archive | change 归档进 `freezed_changes.7z.archived`（命令 `archive freeze`） |

## D. TUI 端词汇（标识符保留，中文别名在此备查）

固定词与弃用词的 SSOT：[TUI信息呈现与固定区词汇.md](./TUI信息呈现与固定区词汇.md)。常用别名：

| 标识符 / 词 | 中文别名 | 含义 |
|---|---|---|
| 固定区 | 固定框架区 | 界面中非滚动内容的骨架区（状态条、页脚、待办栏等） |
| dock | 输入坞 | 底部 editor 槽所在固定区 |
| plate | 命令面板组件 | `Plate` 组件（命令 / 设置面板底座） |
| bang | shell 直通前缀 | `!` / `!!` 用户直接跑终端命令 |
| cue | 预告短句 | busy 期右下角短提示（产品端不渲染；引擎 / harness 保留） |
| 尾插 / 顶插 | 尾部追加 / 顶部插入 | 滚动提示的两种插入位置策略 |
| `session_popup` | 覆盖弹出框（弃称「抽屉」） | 瞬态右侧浮层（`alt+i`，动作 `app.session.popup`）：只覆盖对话条目区域、正文不重排 |
| `session_sidebar` | 侧栏（弃称「驻列」） | 常驻右列（`alt+u`，动作 `app.session.sidebar`）：内容区让宽重排的第二列；实验特性，现施工中占位 |
| designing | designing 组合 | 交互表面的 debug 叶（`xylitol tui designing`）：同一套 TUI client 挂假 Host，用场景槽切命名可达态。**不是**顶层表面，**不是**工具行 `args_preview`。关槽后经 `/designing` 再开场景槽（仅此组合列出且置顶） |
| designing preview | 预览设计 | designing 内把某场景注入同一 TUI 画布的那一幕；切场景仍走场景槽 |

## E. 内部编号

| 形态 | 含义 | 查询 |
|---|---|---|
| `c####` | llman change id | `llman-sdd archive freeze --list`（冷归档 id → slug 清单）；搁置提案见 `llmanspec/delayed-changes/` 目录名 |
| `ath##` / `atm##` / `ati##` / `ce##` 等 | 各 capability spec 需求 id | 所在 `llmanspec/specs/<capability>/<capability>.feature`（`@req:` 规则块） |
| `qg##` / `ptim##` / `w8` | 票内局部代号 | 冻结归档（`llman-sdd archive freeze --list` / `freezed_changes.7z.archived` 清单） |

新写作规范：id 单独引用须带 ≤12 字语义尾（如 `c2040 tui-mouse-click-fold-triangle`）。
