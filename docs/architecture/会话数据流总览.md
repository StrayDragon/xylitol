# 会话数据流总览

> 一份会话数据有几条去向：进模型的消息列表、落盘的会话真源、断点后的恢复
> 投影、端上的展示渲染、旁路的日志。本文钉住**每条会话数据流的真值源、读写权与流向**，
> 以及它们之间的禁令。各数据流内部的产品 MUST 在 `llmanspec/specs/**`；本文是导航与心智图。

## 五条会话数据流

| 数据流 | 真值源 | 谁写 | 谁读 | 一句话边界 |
|---|---|---|---|---|
| **LLM API 消息列表**（模型输入体） | 会话历史经「会话→模型投影」 | host | provider | 模型只见投影后的消息（system / 用户 / 助手 / 工具调用与结果 / 压缩摘要） |
| **会话 SSOT**（持久真源） | 会话条目树：消息 + 领域快照条目 | host | host、恢复投影、导出 | 一切持久语义状态的唯一写者与真相；latest-wins |
| **恢复投影**（resume / 分支回看） | 会话 SSOT | 恢复路径 | 端 | 从 SSOT 重建端上视图，MUST 与直播同构 |
| **client 展示层**（TUI / 之后的 GUI） | 类型化事件（live）+ SSOT 快照（恢复） | 端本地折叠态等纯展示态 | 用户 | 端只渲染：从类型化载荷投影，MUST NOT 解析语义字符串或另立第二真源 |
| **日志**（观测） | provider trace / 结构化日志 | host | 人与诊断工具 | 永不进渲染、永不进模型体、永不进会话 SSOT |

## 流向图

```text
              ┌──────────────────────────────────────────────┐
              │                 会话 SSOT                    │
              │  消息条目 + 领域快照（如 Todo 全量快照）        │
              └──────┬───────────────────────┬───────────────┘
                     │ 会话→模型投影           │ 恢复投影（travel/fork/resume）
                     ▼                       ▼
        ┌─────────────────────┐   ┌─────────────────────┐
        │  LLM API 消息列表    │   │  端上视图（重建）     │
        └─────────────────────┘   └─────────────────────┘
                     ▲                       ▲
                     │ 工具调用/结果（模型接口） │ 类型化状态事件（live）
              ┌──────┴───────────────────────┴───────┐
              │            host（模型 / 工具执行）      │──▶ 日志（旁路，只写）
              └──────────────────────────────────────┘
```

## 硬规则（跨数据流禁令）

- **领域状态变更 MUST 以类型化事件对外发布**（载荷为结构化快照），端 live 投影从
  事件取数；MUST NOT 要求端解析工具结果文本或调用参数才能维持状态视图。旧端对
  未识别事件 MUST 可降级忽略。
- **SSOT 是唯一写真相**：事件丢了可从 SSOT 恢复（恢复投影永远读 SSOT）；MUST NOT
  出现「只存在于事件里、SSOT 读不到」的业务状态。
- **模型体与展示互不冒充**：给模型看的结果形态（如工具结果 JSON）是模型接口，
  不因端上好看而改；端上呈现（清单、摘要、着色）不进模型体。领域快照 MUST NOT
  经会话→模型投影进入前缀（模型通过工具读写它，不靠前缀注入）。
- **日志严格旁路**：MUST NOT 把日志当数据面（不渲染、不重放、不作为恢复源）。
- **恢复投影与直播同构**：同一份会话内容，直播 flush 与恢复重建产出的端上视图
  形态 MUST 一致（幂等可测）；呈现 helper MUST 两路共用。

## worked example：Todo 清单

| 数据流 | Todo 的形态 |
|---|---|
| 会话 SSOT | 领域快照条目（`agent_todo`）：每次成功写入追加一条全量快照，latest-wins |
| LLM 消息列表 | 仅工具调用参数与工具结果（JSON）；快照本身不进前缀；压缩丢快照时 host 重补一条 |
| 类型化事件 | 写入成功后发布 `TodoUpdated`（全量清单快照）；未升级端降级忽略 |
| client 展示 | live 清单行从事件刷新；工具块头部为条目计数摘要、展开正文为与清单行同字形表的勾选清单；恢复从 SSOT 快照重建，与直播同构 |
| 日志 | 工具调用与结果照常进 provider trace；无额外 Todo 专属日志面 |

反例（本表钉死前后的对照，防回潮）：端在工具结束事件里解析结果 JSON 字符串来
刷新清单——事件面与恢复面不同构，第二产品端要再猜一遍形状；工具块的展开正文
直接倾倒原始 JSON——模型接口形态泄漏成了展示形态。
