# 多模态理解

> 音频、视频等理解路径；**仅部分可配置模型**可用。
> **图像附件已在 architecture**；本文只留音 / 视频与档案模态声明。
> 现状对齐：2026-07-20。

## 产品规则

| MUST | 禁止 |
|---|---|
| 模态能力与**模型档案**绑定；不支持则清晰拒绝或降级 | 对不支持的模型假装已理解媒体 |
| 未配置多模态模型时零成本 | 默认拉起媒体管线 |
| 用户可感知：本模型支持哪些模态 | 静默丢附件 |

| 模态 | 方向 |
|---|---|
| 图像 | **已落地**（见 architecture）；不在本文重复交付 |
| 音频 | 可配置模型可用 |
| 视频 | 可配置模型可用 + 长度/采样产品规则 |

## 分阶段（可认领切片）

| 阶段 | 用户可感知结果 | 备注 |
|---|---|---|
| **M1 档案模态声明 + 诚实拒绝** | 模型档案可声明支持的模态；不支持时明确提示，不伪造「已听/已看」 | **优先**；可先于编解码管线打磨 |
| **M2 音频理解** | 支持档案下可附加音频并进入对话语境 | 零成本默认仍成立 |
| **M3 视频理解** | 支持档案下可附加视频；长度/采样规则可感知 | 可单独波次；规则提案前钉清 |

## BDD 意图示例

**场景：不支持时诚实**
Given 当前模型不支持视频
When 用户附加视频
Then 产品明确提示不可用，不伪造「已观看」

**场景：未配置零成本**
Given 用户未配置任何音视频理解模型
When 仅进行文本与已支持的图像路径
Then 不拉起音视频管线，行为与今日主线一致
