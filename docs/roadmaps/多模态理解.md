# 多模态理解

> 音频、视频等理解路径；**仅部分可配置模型**可用。图像附件已在 architecture。
> 现状对齐：2026-07-18。

## 产品规则

| MUST | 禁止 |
|---|---|
| 模态能力与**模型档案**绑定；不支持则清晰拒绝或降级 | 对不支持的模型假装已理解媒体 |
| 未配置多模态模型时零成本 | 默认拉起媒体管线 |
| 用户可感知：本模型支持哪些模态 | 静默丢附件 |

| 模态 | 方向 |
|---|---|
| 音频 | 可配置模型可用 |
| 视频 | 可配置模型可用 + 长度/采样产品规则 |
