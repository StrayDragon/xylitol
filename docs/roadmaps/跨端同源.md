# 跨端同源

> **约束板**：凡已开放的产品端，对会话 / 改向 / 能力开关必须**语义同源**；表现可异。
> Print / TUI / Server 同构已在 architecture。第二产品端定为 **gpui 桌面（Linux/Wayland）**（见 [`Gpui桌面客户端.md`](./Gpui桌面客户端.md)）；Web 控制台搁置（见 Cloud-Agent）。本文**不**交付 gpui 或 Web 壳。
> gpui ↔ TUI：公共能力一套学习成本、动作语义同源、快捷键尽量同构、端专属能力可分叉。
> 观测出口统一走 fastrace → 可选 OTLP/Langfuse（见 [OTEL与Langfuse观测.md](./OTEL与Langfuse观测.md)），**不**另起「检视事实源」产品端。

## 本文是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 跨端语义 MUST 与可验证意图 | Web 控制台 / 多工作区产品交付 |
| 给即时设置、编排等挂「同源」约束 | 要求像素或键位一致 |
| 可在无第二端壳时先钉共享会话语义 | 假装今日已有 gpui / Web 端 |

搁置的 Web 应用端 → [Cloud-Agent与Web控制台.md](./Cloud-Agent与Web控制台.md)。

## 同源 vs 同貌

| 同源（MUST） | 同貌（不要求） |
|---|---|
| 驱动命令与事件闭集 | 像素布局、信息密度、控件皮肤 |
| 会话 / 队列 / 中止 / 分支 | — |
| 即时设置覆盖集；Sub-agent / Loop 关键状态 | — |
| **公共能力**的动作语义与学习模型（用户「要学什么」一致） | 某一端**独有**能力的交互 |
| 公共能力的快捷键 / 发现路径 **SHOULD 尽量同构**（OS 修饰键 ⌘/Ctrl 等可映射） | 强制每个物理键帽字节级相同；禁止把端专属增强（点击等）写成公共 MUST |

> **分界**：先问「这是不是两端都会有的能力？」——是 → 语义与理解成本必须一套，键位尽量一套；否（纯 TTY / 纯 GUI）→ 可分叉，但仍勿污染公共词汇。

## 产品规则

| MUST | 禁止 |
|---|---|
| 两端描述同一会话时状态可对上 | 静默分叉第二套会话语义 |
| 能力开闭（即时设置）共用事实 | 某一端已关、另一端仍当已开 |
| 新开放端接入时对齐全套同源词汇 | 为赶某一端另起一套进度故事 |
| 设计/改 **公共**交互时，按「一套学习成本」验收（含折叠类减噪、改向等） | 只为 TUI（或只为 gpui）发明第二套公共故事；把端专属键位写成公共 MUST |
| 改公共交互相关 roadmap / architecture / 各端 `AGENTS` 前先对齐全部端 | 静默开出「只教某一端」的第二套公共故事 |

> 末行自 `../AGENTS.md` 跨端公共体验节收拢（去重合并，不改语义）；细则以本板为准。

## 分阶段（可认领切片）

| 阶段 | 用户可感知 / 可验证结果 | 备注 |
|---|---|---|
| **M1 同源词汇与事实源清单** | 会话 / 改向 / 覆盖集的跨端约定可审查；公共能力「学习成本一套」写入可审查清单 | **文档+合约意图**；不要求第二端 UI |
| **M1b 长历史 activity 折叠栈** | 公共能力切片示例：两端共用「从输入侧剥开 / 盖上」；动作 id 同源；键位 SHOULD 同构（TUI 默认可配） | TUI 半边（`activity.expandNearest` / `activity.collapseNearest`）已交付；本表只剩 gpui 半边：未开放；≠ session-compact；服从上文「公共 vs 专属」 |
| **M2 即时设置事实源** | TUI 覆盖集可被未来 gpui 只读/写入同一语义 | 与 [运行时即时设置.md](./运行时即时设置.md) M1–M2 对齐 |
| **M3 跨端接续** | 同会话在已开放的 TUI 与 gpui 间切换不矛盾 | **依赖** gpui 端至少有会话壳 |

## 依赖与并行

- **被依赖**：即时设置、Sub-agent、Loop、Cloud-Agent 的跨端叙事。
- **不阻塞**：Tokenizer CLI、TUI 视觉减噪、多模态档案声明（可先 TUI/CLI）、OTLP/Langfuse 出口。
- 现行多 client：[../architecture/库与多客户端.md](../architecture/库与多客户端.md)。

## BDD 意图示例

**场景：跨端接续**
Given 用户在 TUI 进行中的会话
When 在 gpui 打开同一会话
Then 进度、队列与最近工具结果可理解且不矛盾

**场景：即时设置同源**
Given 用户在 gpui 关闭了某后置能力覆盖（如 DAP）
When 回到 TUI 开启下一波次
Then 覆盖一致，且下一波次按关闭该能力装配

## 支线与方向

| 支线 | 意向 |
|---|---|
| **同源契约测试意图** | 跨端状态对拍的 BDD 意图清单（可先无第二端 UI，钉词汇） |
| **覆盖集只读投影** | 第二端未开写时仍能只读看见 TUI 覆盖（M2 轻量） |
| **事件闭集变更检查单** | 新生命周期词必须双端登记（流程向，非进度板） |
| **Eval harness 端无关** | 回归跑 Print/CLI，不要求 TUI/gpui 像素同源 |
| **压缩/cache 状态同源** | 两端看到的「正在压缩 / cache 未知」语义一致 |
| **Activity 折叠栈（expandNearest / collapseNearest）** | 旧 turn 中间操作 → L2/L3 摘要；从输入侧双向栈；与 `/session-compact` 分层。TUI 半边已交付（`src/app/tui/activity_fold`）；候选只剩 gpui 半边：开放时按同源语义接入 |
| **交互模型 oneof（终端选区 ↔ 应用内选区）** | TUI 半边已交付：词汇与产品缺省以 [`../architecture/TUI信息呈现与固定区词汇.md`](../architecture/TUI信息呈现与固定区词汇.md)（**Inline** / **ApplicationOwned**，产品缺省 AO）为准，实现指针见该文「与代码的对应」。候选只剩 gpui 半边：开放时两端同源（应用内选区语义、复制出口一致） |
