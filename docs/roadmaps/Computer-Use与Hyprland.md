# Computer Use 与 Hyprland

> 深度集成 computer use：理解并操作用户电脑。支持范围刻意收窄为 **Linux / Hyprland（Wayland）** 技术栈。
> 现状对齐：2026-07-17。

## 用户怎么碰到

- 希望 agent 能看屏幕、点窗口、操作桌面完成「超出仓库编辑」的任务；
- 个人环境是 Arch + Hyprland 一类；不承诺「任意 OS 任意桌面」。

## 产品边界

| 要 | 不要 |
|---|---|
| Linux + Hyprland（Wayland）路径做深 | 早期就铺 Windows/macOS 全家桶 |
| 会话内启用；默认不影响普通编码主线 | 启动即注入桌面控制 |
| 权限与破坏性操作可感知 | 静默全局键鼠劫持 |
| 与工具主线故事一致（可中止、可看见进度） | 旁路驱动、事件不可见 |

## 能力心智

```mermaid
flowchart LR
  Enable["会话启用 Computer Use"] --> Perceive["感知 · 窗口/区域/可选帧"]
  Perceive --> Act["动作 · 输入与窗口操作"]
  Act --> Loop["纳入同一轮对话与中止语义"]
```

## BDD 意图示例

**场景：默认不影响**
Given 用户未启用 Computer Use
When 普通编码对话
Then 无桌面控制常驻行为

**场景：Hyprland 上完成可见任务**
Given 已在支持环境启用
When 用户要求操作某窗口完成任务
Then agent 在可观察进度下执行，用户可中止

**场景：非支持环境诚实**
Given 桌面会话不是承诺栈
When 用户尝试启用
Then 明确不支持，而非半残执行

## 分阶段

| 阶段 | 用户可感知结果 |
|---|---|
| M1 感知只读 | 窗口列表/焦点等可查询（低破坏） |
| M2 受限动作 | 明确白名单动作 + 中止 |
| M3 视觉闭环 | 与多模态/截图策略协同（若需要） |
| M4 深化 | 工作流级任务（仍限 Hyprland 栈） |

## 依赖与并行

- 可与多模态（截图理解）协同，但**不**互相阻塞。
- 安全与信任叙事需单独产品规则（破坏性默认关）。

## 支线与方向

| 支线 | 意向 |
|---|---|
| **截图抽稀** | 帧率/区域采样进模型前压缩（挂 [上下文缓存与极致压缩.md](./上下文缓存与极致压缩.md) / 多模态） |
| **只读桌面探针** | 长期停在 M1：窗口列表供编码任务，不开放键鼠 |
| **破坏性二次确认档** | 关闭窗口 / 输入密码类动作的显式确认 UX |
| **录制回放排障** | 桌面动作轨迹进 Langfuse（可选调试档） |
| **非 Hyprland 诚实矩阵** | 其它 Wayland 合成器「明确不支持」清单，防半残期望 |
