# TUI 视觉与信息表达

> 状态减噪与主题密度打磨。工具人类可读与 provenance footer **已在** architecture。
> 现状对齐：2026-07-20。

## 仍候选（相对已落地）

| 仍候选 | 已落地（勿再当候选主线） |
|---|---|
| 忙碌 / 队列 / 中止表达进一步统一、弱化重复徽章 | 工具主视线人类可读 + 可展开 |
| 主滚动区默认少噪声，次级元数据可折叠 | Footer 用量 provenance 诚实标注 |
| DESIGN 下信息层级与对比度打磨 | 生命周期闭集 + 跨面词汇 |

## 产品目标

| 要 | 不要 |
|---|---|
| 忙碌/队列/中止表达进一步统一、弱化重复徽章 | 每条内部事件都抢视线 |
| 在 DESIGN 下做信息层级与对比度打磨 | 为「信息全」牺牲可扫读 |
| 减噪有可感知契约时可走 SDD | 把纯主题微调硬写成 MUST 阻塞主线 |

## 分阶段（可认领切片）

| 阶段 | 用户可感知结果 | 路径提示 |
|---|---|---|
| **M1 状态减噪** | 一轮大量内部进度时，主区仍保住助手结论与工具结果；长史旧操作可收成活动摘要 / Worked for（跨面语义见 [跨面同源.md](./跨面同源.md) M1b） | **TUI 已交付**；gpui 仍候选 |
| **M2 忙碌/队列/中止统一** | 同类状态不再多徽章抢视线 | 有合约则 SDD；否则 quick |
| **M3 主题密度** | DESIGN 对比度 / 密度打磨，不改语义 | **默认 quick**（不改行为合约） |

## 依赖与并行

- **可并行**于 Tokenizer / 多模态 / 即时设置；**不依赖**词表下载。
- 约束边界见 [../architecture/用户可见事件.md](../architecture/用户可见事件.md)；本篇不复述已兑现正文。

## BDD 意图示例

**场景：噪声默认折叠**
Given 一轮中产生大量内部进度
When 用户只看主滚动区
Then 不因次级元数据刷屏而丢掉助手结论与工具结果

**场景：状态不抢结论**
Given 同时存在忙碌、队列与可中止提示
When 助手正在输出结论性文本
Then 状态表达可读但不压过主文本与工具结果

## 支线与方向

| 支线 | 意向 |
|---|---|
| **Cache / 压缩微徽章** | 用量区诚实显示 cache hit 或「压缩中」（挂缓存 roadmap；不刷屏） |
| **Eval 跑批状态** | 后置：开发者跑回归时的非交互状态条（非日常用户路径） |
| **密度三档** | 紧凑 / 标准 / 宽松；纯表现，默认 quick |
| **色弱 / 高对比预设** | DESIGN 可访问性切片 |
| **工具结果折叠记忆** | 会话内记住用户展开偏好（表现态，慎升 MUST） |
