| 已有 | 缺口（本篇） |
|---|---|

## 用户怎么碰到

| 场景 | 痛点 | 要给的 |
|---|---|---|
| 学键 | 靠习惯 + 局部提示 | **主路径 = 文档 / Web 学习页**；程序内保持旁注，不默认塞百科 slash |
| agent 忙碌时切模型 / 看主题 / 浏览会话列表 | `/model` 开列表、`/theme`、`/session-resume` 等被 busy 拒 | **即时列表**与 scroll/provider 解耦；Resume **可浏览**、**不可 switch**（见 M0） |
| busy 时误点切换会话 | 静默失败或整面板打不开 | **滚动提示**（`UiEntry::ScrollNotice`）说明须等 turn 结束或 Esc 中止后再 switch |
| 改键 | 只能手改 JSON | 后期可配置 UI / Web；短期 JSON 仍够用 |
| 模拟按键学习 | 无交互键盘图 | **延后**：Web 面；见调研 |

## 产品规则（候补）

| MUST（兑现时） | 禁止 |
|---|---|
| 旁注和弦跟 `KeybindingsManager` 实际绑定走 | footer / 静图顶栏堆完整键墙 |
| 公共能力发现路径跨面一套学习成本（同源） | 为 TUI 另造第二套公共故事，却把 Web 专属键盘图写成公共 MUST |
| busy 闸用单一表（现 `slash_allowances`）扩展，不平行 fork | 静默解冻产品 Ctrl+P Command Plate（本波不做；和弦已被 Resume `app.session.togglePath` 占用） |
| 列表打开不依赖 scrollback 内容 / LLM provider 是否已响应 | 把「改全局 YAML 档案」做成运行时 Settings stub |
| busy 下 Resume：**打开/浏览 Allow**；**switch Reject** + **滚动提示**说明等待 turn 完成或 Esc 中止 | busy 下静默 switch；或用假 system 消息冒充滚动提示 |

### M0 busy 闸（已拍板 · 认领时钉进合约）

相对现行 `slash_allowances`（Allow / Reject）。Resume 的 **打开** 与 **switch** 拆成两闸：

| Slash / 动作 | 现行 busy | M0 | 理由 |
|---|---|---|---|
| `/model` 开列表 | Reject | **Allow**（确认仍走 NextTurn / 下轮预告） | 即时列表 |
| `/model <id>` 直选 | Allow | 保持 Allow | 已落地 |
| `/theme` | Reject | **Allow** | 纯 chrome |
| `/mcp` | Allow | 保持 | 已落地 |
| `/session-resume` **打开面板 / 浏览 / 搜索 / 折叠** | Reject | **Allow**（只读浏览） | 与 scroll/provider 无关 |
| `/session-resume` 内 **Enter switch**（及等价切会话） | —（面板进不去） | **Reject**：MUST NOT 切换；MUST 尾随 **滚动提示**（`UiEntry::ScrollNotice`），大意：须等待本轮对话 turn 完成，或 Esc 中止当前对话后再切换 | 列表可看、拓扑不可动 |
| `/session-tree` `/session-fork` `/session-new|clone|import` | Reject | 保持 Reject | 拓扑 / 分叉 |
| `/reload` `/trust` | Reject | 保持 Reject | 写盘 / 重装 |
| `/session-compact` `/session-export` `/session` dump / `/history-copy-last` / `/exit` | Allow | 保持 | 已落地 |

滚动提示文案宜短、可本地化；MUST 用词汇表中的 **滚动提示**，勿称 system 消息。
（M0 拒 switch 落点已由 **壳层通告** 兑现，见 architecture 词汇表；上表「滚动提示」字样留作历史意图对照。）

## BDD 意图示例（候补）

**场景：busy 开模型列表**
Given agent 正在流式输出
When 用户执行无参 `/model`
Then 打开模型列表且 MUST NOT 因 busy 被拒
And 确认后的生效边界仍遵循既有 NextTurn / 下轮预告语义

**场景：busy 浏览 resume 但不可 switch**
Given agent busy
When 用户执行 `/session-resume`
Then 打开 Resume 面板且可浏览列表
When 用户对某会话确认 switch
Then MUST NOT 切换会话
And MUST 尾随一条滚动提示，说明须等 turn 完成或 Esc 中止后再操作

**场景：busy 仍拒 reload**
Given agent busy
When 用户执行 `/reload`
Then 拒绝并给出可理解提示
And MUST NOT 开始热重载

## 支线与方向

| 支线 | 意向 |
|---|---|
| **`/hotkeys`（原 M1）** | 若用户明确要程序内目录再用；名称优先 `/hotkeys` 而非 `/help`；动态跟 manager |
| **默认键冲突审计** | 启动或 `/reload` 报告跨上下文同键 |
| **建议改键清单** | 见调研附录；投诉驱动 |
| **skill slash 进 editor catalog** | 补全与 GetCommands 对齐 |
| **Command Plate 重开** | 须先重分配 Ctrl+P |
| **导出默认目录 JSON** | 喂给学习页 / 文档生成 |
