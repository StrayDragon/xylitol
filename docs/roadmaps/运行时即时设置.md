# 运行时即时设置

> **已落地**（模型 / thinking run 绑定 + 选中即时反映）见 [../architecture/运行时即时设置.md](../architecture/运行时即时设置.md)。
> 本文只留**未兑现**候选：会话能力覆盖盘与多面同源。
> 与 `/reload`（资源热重载）分语义——见 [../architecture/配置与档案.md](../architecture/配置与档案.md)。

## 用户怎么碰到（候选）

- 本会话临时关 LSP / 开 DAP / 屏蔽某 MCP，**不**静默写回全局档案；
- 变更在**下一装配波次**再生效；本波次不中途拆已开工承诺（除非明示规则）；
- 能看到「当前覆盖」与「长期档案」的差别；
- gpui 开闸后读写**同一**覆盖事实源。

## 关键词汇（候选追加）

| 词 | 含义 |
|---|---|
| **长期档案** | 磁盘配置 / profile；重启后仍在 |
| **会话覆盖** | 仅本会话（或明示更短寿命）的能力开关；**不**静默写回全局 |
| **波次** | 能力装配单元：通常对齐下一 turn；与模型 run 绑定同「当前不变、下一边界再生效」心智 |

已落地词（active / pending / turn / in-flight）见 architecture。

## 产品规则（候选切片）

| MUST | 禁止 |
|---|---|
| 会话覆盖与长期档案可区分 | 静默改写全局配置 |
| 能力变更在约定波次才作用于装配 | 暗示已改却仍按旧能力跑完且 UI 不说明 |
| 覆盖待生效复用 status 区既有提示位心智 | 另造一套与模型待生效无关的幽灵墙 |
| 可启用 / 停用 / 屏蔽单项能力 | 只能杀进程才能切换 |
| 覆盖集在已开闸面可查；多面时同源 | 两面「已启用」不一致 |
| 未启用保持零成本 | 关 UI 仍占重资源 |
| **先 TUI 可用**；gpui 随后对齐 | 因 gpui 未开而阻塞 TUI 覆盖盘 |

## 分阶段（可认领切片）

| 阶段 | 用户可感知结果 | 备注 |
|---|---|---|
| **M1 TUI 覆盖盘 + 下一波次** | TUI 可改能力覆盖；确认下一波次生效；本波次不偷换装配 | 策略变更须重绑系统提示片段（见 llmanspec `c1605` purpose-draft） |
| **M1b 提示片段机制** | 能力/tool 策略切换时自动注入/撤下短提示，用户无需另贴 SYSTEM | 可先于完整覆盖盘 UI；`c1605` → 默认策略文案 `c1610` |
| **M2 可观察覆盖集** | 用户能看见「当前覆盖 vs 长期档案」 | 与 M1 可同一 change 或紧随 |
| **M3 第二面同源** | gpui 读写同一覆盖事实源 | 挂 [跨面同源.md](./跨面同源.md) M2；gpui 壳后置 |
| **M4 挂接后置能力** | LSP/DAP/… 真实开闭进盘 | 各能力 roadmap 就绪后再接；盘本身不假装能力已交付 |

## 依赖与并行

- **约束**：[跨面同源.md](./跨面同源.md)（多面时）；TUI 可先于 gpui。
- **被依赖**：LSP / DAP / Loop / Sub-agent 的「会话内开闭」叙事。
- **可并行**：Tokenizer、多模态、TUI 视觉、OTLP/Langfuse 出口。

## 开放问题

- 覆盖默认是否**会话结束即丢**？（建议默认是；持久化需显式产品决定）
- 能力类已开工工具/LSP：中途拆与不拆的明示规则默认值？（建议默认不拆）

## BDD 意图示例（候选）

**场景：下一波次能力关闭**
Given 本波次正在使用某后置能力（如 LSP）
When 用户关闭该能力的即时设置
Then 本波次不中途拆掉已开工承诺（或按明示规则）；**下一波次**不再装配该能力
And 用户能从覆盖可见面理解尚未对本波次生效

**场景：不写回全局**
Given 用户仅在本会话关闭某能力
When 查看长期档案 / 新开无关会话
Then 全局与其它会话不被静默改写

## 支线与方向

| 支线 | 意向 |
|---|---|
| **压缩/cache 策略档进盘** | 保守/均衡/激进作为会话覆盖（挂 [上下文缓存与极致压缩.md](./上下文缓存与极致压缩.md)） |
| **一键「演示档」** | 临时关后置重能力 + 开观测，便于录屏/排障 |
| **覆盖导出/导入** | 把本会话覆盖拷到另一会话（显式，非静默写全局） |
| **Eval 固定覆盖** | 回归 harness 锁定覆盖集，避免本地盘状态污染实验 |
| **提示片段商店心智** | M1b 深化：按能力组合的短提示可审查、可关 |
