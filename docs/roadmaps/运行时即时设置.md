# 运行时即时设置

> 对话进行中调整能力开关与偏好：**生效于下一波次对话**（下一轮 / 下一次模型调用波次），不必重启进程。
> 用于随时屏蔽、关闭、启用如 LSP、DAP、某类工具、子 agent 等。
> 现状对齐：2026-07-17。

## 用户怎么碰到

- 本会话突然不想再喂诊断（关 LSP），或要开调试（开 DAP）；
- 不想改磁盘上的长期配置，只想「接下来几轮」换一套能力；
- 改完应**立刻心里有数**：何时生效、当前生效集是什么。

## 产品规则

| MUST | 禁止 |
|---|---|
| 即时设置与长期档案可区分（会话覆盖 vs 持久配置） | 静默改写用户全局配置且无提示 |
| 变更说明**下一波次**才作用于模型/工具装配 | 暗示「已改」却仍按旧能力跑完一整波 |
| 可随时启用 / 停用 / 屏蔽单项能力（LSP、DAP、…） | 只能杀进程重开才能切换 |
| 当前覆盖集在 TUI/Web **同源**可查 | 两面显示不一致的「已启用」列表 |
| 未启用的能力保持零成本心智 | 关掉 UI 开关却仍占着重资源 |

## 生效模型（产品）

```mermaid
flowchart LR
  Now["用户切换即时设置"] --> Ack["界面确认：下一波次生效"]
  Ack --> Wave["当前波次仍按旧装配跑完"]
  Wave --> Next["下一波次按新装配"]
```

「波次」= 用户可理解的下一次完整模型/工具装配边界（通常即下一轮对话启动时）；具体命名在落地时与 architecture 对齐。

## 与后置能力的关系

| 能力例 | 即时设置角色 |
|---|---|
| LSP / lspz | 会话内开闭；见 [LSP会话集成.md](./LSP会话集成.md) |
| DAP / dapz | 会话内开闭；见 [DAP调试集成.md](./DAP调试集成.md) |
| Computer Use / 多模态管线 | 可临时屏蔽，避免误触 |
| Sub-agent | 可禁止派生；见 [Sub-Agent编排.md](./Sub-Agent编排.md) |
| MCP 某服务器 | 可屏蔽单个服务器（方向上纳入同一开关盘） |

## BDD 意图示例

**场景：下一波次生效**
Given 本波次正在使用 LSP 诊断
When 用户在本波次中关闭 LSP 即时设置
Then 本波次不中途拆掉已开工的 LSP 承诺（或按明示规则处理）；**下一波次**不再装配 LSP

**场景：可查当前覆盖**
Given 用户启用了 DAP 并屏蔽了某 MCP
When 打开设置/状态面板（TUI 或 Web）
Then 看到与对方面一致的覆盖列表与「下一波次生效」提示

**场景：恢复长期默认**
Given 存在会话级覆盖
When 用户清除即时覆盖
Then 下一波次回到档案默认，且零成本能力真正卸下

## 分阶段

| 阶段 | 用户可感知结果 |
|---|---|
| M1 开关盘心智 | 会话覆盖 vs 持久配置分离；生效文案统一 |
| M2 核心能力接线 | LSP / DAP / 关键工具类可即时开闭 |
| M3 多面同源 | TUI 与 Web 同一覆盖事实源 |
| M4 细粒度 | 单 MCP、单模态、子 agent 策略等 |
