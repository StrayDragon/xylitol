# 运行时即时设置

> 对话中调整能力开关：**下一波次**生效，不必重启。
> 与已落地的 `/reload`（资源热重载）不同——见 [../architecture/配置与档案.md](../architecture/配置与档案.md)。
> 现状对齐：2026-07-18。

## 用户怎么碰到

- 本会话临时关 LSP / 开 DAP；
- 不改磁盘长期配置，只改「接下来几轮」；
- 心里有数：何时生效、当前覆盖集是什么。

## 产品规则

| MUST | 禁止 |
|---|---|
| 会话覆盖与长期档案可区分 | 静默改写全局配置 |
| 变更说明**下一波次**才作用于装配 | 暗示已改却仍按旧能力跑完 |
| 可启用 / 停用 / 屏蔽单项能力 | 只能杀进程才能切换 |
| 覆盖集在 TUI/Web 同源可查 | 两面「已启用」不一致 |
| 未启用保持零成本 | 关 UI 仍占重资源 |

```mermaid
flowchart LR
  Now["切换即时设置"] --> Ack["确认：下一波次生效"]
  Ack --> Wave["当前波次按旧装配"]
  Wave --> Next["下一波次按新装配"]
```

## 与后置能力

| 能力例 | 角色 |
|---|---|
| LSP / DAP | 会话内开闭 |
| Computer Use / 多模态 | 可临时屏蔽 |
| Sub-agent | 可禁止派生 |
| MCP 某服务器 | 可屏蔽单个 |

## BDD 意图示例

**场景：下一波次生效**
Given 本波次正在使用 LSP
When 用户关闭 LSP 即时设置
Then 本波次不中途拆掉已开工承诺（或按明示规则）；**下一波次**不再装配 LSP
