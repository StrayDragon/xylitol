# 运行时即时设置

> 对话中调整能力开关：**下一波次**生效，不必重启。
> 与已落地的 `/reload`（资源热重载）不同——见 [../architecture/配置与档案.md](../architecture/配置与档案.md)。
> 现状对齐：2026-07-20。

## 用户怎么碰到

- 本会话临时关 LSP / 开 DAP；
- 不改磁盘长期配置，只改「接下来几轮」；
- 心里有数：何时生效、当前覆盖集是什么。

## 关键词汇

| 词 | 含义 |
|---|---|
| **长期档案** | 磁盘配置 / profile；重启后仍在 |
| **会话覆盖** | 仅本会话（或明示更短寿命）的能力开关；**不**静默写回全局 |
| **波次** | 一次「装配后跑起来」的对话工作单元（通常对应新一轮模型调用装配边界）；切换说明对**下一**波次生效 |

## 产品规则

| MUST | 禁止 |
|---|---|
| 会话覆盖与长期档案可区分 | 静默改写全局配置 |
| 变更说明**下一波次**才作用于装配 | 暗示已改却仍按旧能力跑完 |
| 可启用 / 停用 / 屏蔽单项能力 | 只能杀进程才能切换 |
| 覆盖集在已开闸面可查；多面时同源 | 两面「已启用」不一致 |
| 未启用保持零成本 | 关 UI 仍占重资源 |
| **先 TUI 可用**；Web 随后对齐 | 因 Web 未开而阻塞 TUI 覆盖盘 |

```mermaid
flowchart LR
  Now["切换即时设置"] --> Ack["确认：下一波次生效"]
  Ack --> Wave["当前波次按旧装配"]
  Wave --> Next["下一波次按新装配"]
```

## 与后置能力

| 能力例 | 角色 |
|---|---|
| LSP / DAP | 会话内开闭 |
| Computer Use / 多模态 | 可临时屏蔽 |
| Sub-agent | 可禁止派生 |
| MCP 某服务器 | 可屏蔽单个 |

## 分阶段（可认领切片）

| 阶段 | 用户可感知结果 | 备注 |
|---|---|---|
| **M1 TUI 覆盖盘 + 下一波次** | TUI 可改覆盖；确认下一波次生效；本波次不偷换装配 | **优先**；不依赖 Web |
| **M2 可观察覆盖集** | 用户能看见「当前覆盖 vs 长期档案」 | 与 M1 可同一 change 或紧随 |
| **M3 Web 同源** | Web 读写同一覆盖事实源 | 挂 [Web与TUI同源.md](./Web与TUI同源.md) M2；Web 壳后置 |
| **M4 挂接后置能力** | LSP/DAP/… 真实开闭进盘 | 各能力 roadmap 就绪后再接；盘本身不假装能力已交付 |

## 依赖与并行

- **约束**：[Web与TUI同源.md](./Web与TUI同源.md)（多面时）；**实现上 TUI 可先于 Web**。
- **被依赖**：LSP / DAP / Loop / Sub-agent 的「会话内开闭」叙事。
- **可并行**：Tokenizer、多模态 M1、TUI 视觉、检视独立页。

## 开放问题（提案前钉清）

- 覆盖默认是否**会话结束即丢**？（建议默认是；持久化需显式产品决定）
- 本波次已开工的工具/LSP：中途拆与不拆的明示规则默认值？

## BDD 意图示例

**场景：下一波次生效**
Given 本波次正在使用某后置能力（如 LSP）
When 用户关闭该能力的即时设置
Then 本波次不中途拆掉已开工承诺（或按明示规则）；**下一波次**不再装配该能力

**场景：不写回全局**
Given 用户仅在本会话关闭某能力
When 查看长期档案 / 新开无关会话
Then 全局与其它会话不被静默改写

## 实现接缝（认领时 · 非现行 MUST）

| 接 | 不接 |
|---|---|
| 会话覆盖事实源 → **下一波次**组合根再装配 | 与 `/reload`（磁盘资源热重载）混成同一产品语义 |
| 开关盘只表达覆盖；真实能力仍走各能力自己的零成本装配 | 盘上「已开」却未接线的假装交付 |
| 开闭心智：[../architecture/扩展与开闭.md](../architecture/扩展与开闭.md) | 为开关盘另造插件注册表 |
